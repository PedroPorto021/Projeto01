# Projeto01 - Aplicativo Android

Meu primeiro projeto Android desenvolvido durante meus estudos de Desenvolvimento de Sistemas.

## Sobre o projeto

O aplicativo foi desenvolvido em Kotlin utilizando o Android Studio.

Nesta primeira versão, foram implementados conceitos fundamentais do desenvolvimento Android, como:

- Tela de login
- Validação dos campos de login e senha
- Navegação entre telas
- Envio de informações entre Activities
- Tela inicial personalizada com o usuário
- Botões com eventos de clique
- Mensagens utilizando Toast
- Retorno para a tela de login
- Layouts desenvolvidos em XML

## Tecnologias utilizadas

- Kotlin
- Android Studio
- XML
- Material Design
- Git
- GitHub

## Objetivo

Este projeto faz parte da minha evolução prática nos estudos de Desenvolvimento de Sistemas.

A ideia é continuar aprimorando o aplicativo conforme avanço nos estudos, adicionando novas funcionalidades e registrando minha evolução através do GitHub.
